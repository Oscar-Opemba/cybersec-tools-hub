# Market-readiness map

The hub indexes 13 standalone defensive utilities. Each tool is a local Python project with a documented analyzer contract, bounded I/O, unit and abuse-case tests, secure local web defaults, pinned GitHub Actions, and release guidance.

The collection is not a hosted SaaS platform and should not be marketed as a production multi-user security service without a separate architecture, authentication, privacy, abuse-prevention, and operational review.

Each repository is independently versioned and can be installed with `python3 -m pip install .` or run directly with `python3 app.py`.
